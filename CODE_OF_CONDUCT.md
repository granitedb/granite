# Code of conduct

This project adopts the Contributor Covenant, version 2.1, available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful, assume good faith, keep criticism about the work and not the person, and no harassment of any kind.

Report unacceptable behaviour privately to the maintainers through GitHub's private vulnerability reporting on this repository: open the "Security" tab, choose "Report a vulnerability", and start the title with "Conduct:". Only you and the maintainers can see the report. Reports are handled confidentially.
