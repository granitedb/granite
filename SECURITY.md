# Security policy

The project is in its design phase and has no released versions.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting on this repository ("Security" tab, "Report a vulnerability"). You will get an acknowledgement, and a fix or mitigation plan will be discussed with you before any public disclosure.

## Scope

Once software is released, in scope are: loss or corruption of acknowledged data, violations of the documented consistency guarantees, authentication or authorisation bypass, and remote crashes. Design-level concerns are welcome as ordinary public issues.
